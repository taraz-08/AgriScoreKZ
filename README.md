# AgriScore KZ

**Explainable AI / ML субсидия скоринг платформасы**

ҚР Ауыл шаруашылығы министрлігі · AI inDrive Hackathon 2025 · Кейс 2

---

## Мәселе

Қазақстанда мемлекеттік ауылшаруашылық субсидиялары **"бірінші берген — бірінші алады"** принципімен бөлінеді. Шаруашылықтың нақты тиімділігі, субсидияны игеру тарихы және өсу потенциалы ескерілмейді. Нәтижесінде:

- Тиімді шаруашылықтар уақыт жіберіп кеткені үшін жеңіліп қалады
- Субсидияны дұрыс пайдаланбағандар қайта алады
- Шешім процесі мөлдір емес, комиссия жүктемесі жоғары

**AgriScore KZ** — деректерге және ML-ге негізделген объективті рейтинг жасайды. Финалды шешім адам (комиссия) арқылы қабылданады — AI тек ұсыным береді.

---

## ML Pipeline архитектурасы

```
Деректер жүктеу
    → Preprocessing + нормализация
    → Адаптивті салмақ калибрациясы (дисперсия-негізді)
    → 5 факторлы скоринг (0–100)
    → K-means кластерлеу (4 кластер)
    → Proxy logistic regression (сәтті игеру ықтималдығы)
    → Аномалия анықтау (ережелік + статистикалық)
    → Explainability панелі
    → Shortlist + Комиссия шешімі
```

## Скоринг факторлары

| Фактор | Базалық үлес | Сипаттама |
|--------|-------------|-----------|
| Субсидия тарихы | 25% | Бұрынғы игеру тиімділігі, қайтарым |
| Өнімділік | 30% | Га/т, динамика, орташадан ауытқу |
| Шаруашылық профилі | 20% | Жер, техника, тәжірибе |
| Әлеуметтік-экономикалық | 15% | Жұмыс орны, ауданның дамуы |
| Тәуекел бағасы | 10% | Борыш, тексеру тарихы |

**Шешім матрицасы:**

| Балл | Мәртебе | Ұсыным |
|------|---------|--------|
| 70–100 | Ұсынылды | Shortlist-ке қосу |
| 50–69 | Тексеруде | Комиссия қарауы |
| 0–49 | Ұсынылмайды | Бас тарту |

## ML мүмкіндіктері

### K-means кластерлеу (Pure JS)
- Dependency-сіз, браузерде жұмыс жасайды
- K-means++ инициализация (оңтайлы центройд таңдау)
- 4 кластер, орташа скор бойынша авто-атаулар:
  - 🌟 **Жоғары тиімді** — жоғары балл, жақсы игеру тарихы
  - 📊 **Тұрақты орташа** — орташа балл, тұрақты шаруашылық
  - 🌱 **Өсу потенциалы** — төмен балл, бірақ жеткілікті ресурс
  - ⚠️ **Тәуекелді** — аномалия белгілері, тексеру қажет
- Кластер badge кестеде, детайл бетінде, диаграммада
- Қазақша кластер түсіндірмесі

### Proxy Logistic Regression
- 10 белгі негізінде sigmoid функциясы
- Нәтиже: **сәтті игеру ықтималдығы %**
- Domain-expert калибрацияланған коэффициенттер
- Деректер сапасына байланысты сенімділік деңгейі
- Proxy режим — нақты тарихи деректер жоқ кезде жұмыс жасайды

### Адаптивті салмақ калибрациясы
- Деректер жүктелгенде автоматты талдау
- Əр фактордың вариативтілігін есептейді (дисперсия)
- Формула: `60% × деректер_салмағы + 40% × базалық_салмақ`
- Қолмен / Адаптивті режим toggle
- Қазақша түсіндірме: неге салмақ өсті/кемді

### Аномалия анықтау (9 ереже)
- Өнімділік/скор сәйкессіздігі
- Статистикалық outlier (IQR)
- Субсидия сомасы/жер алаңы қатынасы
- Кіріс/сұраным сәйкессіздігі
- ЖСН бойынша дублікаттар
- Пайдалану деңгейінің кенет өсуі
- Жер/техника балансы

### AI Explainability (Google Gemini 2.5 Flash)
- Əр фактор үшін AI бағасы + қазақша негіздеме
- Серверлік прокси — API кілті браузерге жіберілмейді
- Demo режим — API кілт болмаса pre-written қазақша жауаптар

## Жылдам бастау

### Талаптар
- Node.js 18+

### Іске қосу

```bash
# 1. Репозиторийді клондаңыз
git clone https://github.com/taraz-08/AgriScoreKZ.git
cd AgriScoreKZ

# 2. .env файлын жасаңыз
cp .env.example .env
# GEMINI_API_KEY және логин/пароль мәндерін толтырыңыз

# 3. Серверді іске қосыңыз
node server.js

# 4. Браузерде ашыңыз
# http://localhost:3000
```

## Қауіпсіздік

- API кілті `.env` файлында — сервер жағында ғана
- `.env` `.gitignore`-да — GitHub-қа жүктелмейді
- Барлық AI сұраулар сервер арқылы (path traversal қорғау)
- Нақты логин/пароль тексеру
- Security headers: `X-Content-Type-Options`, `X-Frame-Options`
