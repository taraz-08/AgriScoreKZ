# 🌾 AgriScore KZ

**Merit-based ауылшаруашылығы субсидия скоринг жүйесі**
ҚР Ауыл шаруашылығы министрлігі · AI inDrive Hackathon 2025 · Кейс 2

---

## 📌 Мәселе

Бүгінгі күні мемлекеттік субсидиялар **"бірінші берген — бірінші алады"** принципімен бөлінеді: бюджет таусылғанша кезекте тұрған ие болады. Шаруашылықтың нақты тиімділігі, субсидияны игеру тарихы және өсу потенциалы ескерілмейді.

**AgriScore KZ** деректерге негізделген объективті рейтинг жасайды. Финалды шешім комиссия арқылы қабылданады.

## 🚀 Жылдам бастау

### Талаптар
- Node.js 18+

### Іске қосу

```bash
# 1. Репозиторийді клондаңыз
git clone https://github.com/dimash/AgriScoreKZ.git
cd AgriScoreKZ

# 2. .env файлын баптаңыз
cp .env.example .env
# GEMINI_API_KEY, логин/пароль толтырыңыз

# 3. Серверді іске қосыңыз
node server.js

# 4. Браузерде ашыңыз
# http://localhost:3000
```

## 🧮 Скоринг алгоритмі

5 фактор бойынша **0–100 балл** есептеледі:

| Фактор | Үлес | Макс балл |
|--------|------|-----------|
| 📋 Субсидия тарихы | **25%** | 25 |
| 📈 Өнімділік | **30%** | 30 |
| 🏡 Шаруашылық профилі | **20%** | 20 |
| 👥 Әлеуметтік-экономикалық | **15%** | 15 |
| 🛡️ Тәуекел бағасы | **10%** | 10 |

**Формула:**
```
Score = (F1/30×25×w1) + (F2/30×30×w2) + (F3/20×20×w3)
      + (F4/15×15×w4) + (F5/10×10×w5)
```

**Шешім матрицасы:**

| Балл | Мәртебе | Ұсыным |
|------|---------|--------|
| 70–100 | ✅ Ұсынылды | Shortlist-ке қосу |
| 50–69 | ⚠️ Тексеруде | Комиссия қарауы |
| 0–49 | ❌ Ұсынылмайды | Бас тарту |

## 🤖 AI интеграция

**Google Gemini 2.5 Flash** — сервер арқылы прокси:
- Әр өтінімнің баллын қазақша түсіндіреді
- Тәуекел талдауы жасайды
- Shortlist бойынша жалпы талдау береді
- API кілті браузерге ешқашан жіберілмейді (қауіпсіздік)
- Кілт болмаса — demo режим автоматты іске қосылады
