# AgriScore KZ

**Merit-based ауылшаруашылығы субсидия скоринг жүйесі**

ҚР Ауыл шаруашылығы министрлігі · AI inDrive Hackathon 2025 · Кейс 2

---

## Мәселе

Қазақстанда мемлекеттік ауылшаруашылық субсидиялары **"бірінші берген — бірінші алады"** принципімен бөлінеді: бюджет таусылғанша кезекте тұрған ие болады. Шаруашылықтың нақты тиімділігі, субсидияны игеру тарихы және өсу потенциалы ескерілмейді. Нәтижесінде:

- Тиімді шаруашылықтар уақыт жіберіп кеткені үшін жеңіліп қалады
- Субсидияны дұрыс пайдаланбағандар қайта алады
- Шешім процесі мөлдір емес, комиссия жүктемесі жоғары

**AgriScore KZ** деректерге негізделген объективті рейтинг жасайды. Финалды шешім адам (комиссия) арқылы қабылданады — AI тек ұсыным береді.

---

## Шешім

5 факторлы скоринг алгоритмі өтінімдерді автоматты бағалайды, аномалияларды анықтайды, риск картасын жасайды және комиссияға shortlist ұсынады.

```
Өтінім → Автоскоринг → Аномалия тексеру → AI түсіндірме → Комиссия → Шешім
```

### Скоринг факторлары

| Фактор | Үлес | Сипаттама |
|--------|------|-----------|
| Субсидия тарихы | 25% | Бұрынғы игеру тиімділігі, қайтарым |
| Өнімділік | 30% | Га/т, динамика, орташадан ауытқу |
| Шаруашылық профилі | 20% | Жер, техника, тәжірибе |
| Әлеуметтік-экономикалық | 15% | Жұмыс орны, ауданның дамуы |
| Тәуекел бағасы | 10% | Борыш, тексеру тарихы |

**Шешім матрицасы:**

| Балл | Мәртебе | Ұсыным |
|------|---------|--------|
| 70–100 | Ұсынылды | Shortlist-ке қосу |
| 50–69 | Тексеруде | Комиссия қарауы |
| 0–49 | Ұсынылмайды | Бас тарту |

## Мүмкіндіктер

### Скоринг және аналитика
- 0–100 балл, 5 факторлы алгоритм
- Әрбір факторды жеке бөліп көрсету (explainability)
- Жоғары ықпал ететін оң/теріс факторлар панелі
- Облыс, тренд, scatter диаграммалары

### Аномалия анықтау
9 ереже бойынша автоматты тексеру:
- Өнімділік/скор сәйкессіздігі
- Статистикалық outlier (IQR)
- Субсидия сомасы/жер алаңы қатынасы
- Кіріс/сұраным сәйкессіздігі
- ЖСН бойынша дублікаттар
- Пайдалану деңгейінің кенет өсуі
- Жер/техника балансы

### What-if симуляция
"Егер өнімділік 20%-ға өссе скор қалай өзгереді?" — интерактивті болжам есептеу. Shortlist-ке кіру мүмкіндігі нақты уақытта көрсетіледі.

### Комиссия жұмыс процесі
- Approve / Hold / Reject / Override — 4 шешім
- Комментарий және аудит трейл
- AI тек ұсынады, адам шешеді

### AI интеграция (Google Gemini 2.5 Flash)
- Скор негіздемесін қазақша түсіндіреді
- Тәуекел талдауы
- API кілті браузерге жіберілмейді — сервер прокси
- Кілт болмаса: demo режим автоматты іске қосылады

### Деректер
- Excel / CSV импорт, интерактивті колонка маппинг
- Excel экспорт, PDF есептер
- Drag & drop shortlist реттеу

## Жылдам бастау

### Талаптар
- Node.js 18+

### Іске қосу

```bash
# 1. Репозиторийді клондаңыз
git clone https://github.com/taraz-08/AgriScoreKZ.git
cd AgriScoreKZ

# 2. .env файлын жасаңыз
cp .env.example .env
# GEMINI_API_KEY және логин/пароль мәндерін толтырыңыз

# 3. Серверді іске қосыңыз
node server.js

# 4. Браузерде ашыңыз
# http://localhost:3000
```

### Demo тіркелгілер

| Логин | Пароль | Рөл |
|-------|--------|-----|
| `admin` | `AgriScore2025!` | Администратор |
| `analyst` | `Analyst2025!` | Сарапшы |
| `operator` | `Operator2025!` | Оператор |

### .env мысалы

```env
GEMINI_API_KEY=your_key_here
ADMIN_LOGIN=admin
ADMIN_PASSWORD=your_password
USER1_LOGIN=analyst
USER1_PASSWORD=your_password
USER2_LOGIN=operator
USER2_PASSWORD=your_password
```

Gemini API кілті болмаса — demo режим автоматты іске қосылады.

## Архитектура

```
AgriScoreKZ/
├── server.js              # Node.js HTTP сервер, API прокси
├── .env                   # Құпия баптаулар (git-те жоқ)
├── .env.example           # Үлгі конфигурация
├── .gitignore
└── app/
    ├── index.html         # SPA — 9 бет, hash-routing
    ├── css/
    │   └── main.css       # UI жүйесі, dark mode
    └── js/
        ├── app.js         # Роутер, бет логикасы, Chart.js, PDF
        ├── data.js        # Скоринг, аномалия, what-if, AppState
        └── translations.js # KZ / RU / EN аудармалар
```

### Backend API

| Endpoint | Метод | Сипаттама |
|----------|-------|-----------|
| `/api/login` | POST | Логин/пароль тексеру |
| `/api/gemini` | POST | Gemini API прокси |
| `/api/gemini-status` | GET | AI байланыс күйі |
| `/*` | GET | Статикалық файлдар |

## Қауіпсіздік

- API кілті `.env` файлында — сервер жағында ғана
- `.env` `.gitignore`-да — GitHub-қа жүктелмейді
- Барлық AI сұраулар сервер арқылы (CORS, path traversal қорғау)
- Нақты логин/пароль тексеру — кез-келген логин кірмейді
- Security headers: `X-Content-Type-Options`, `X-Frame-Options`
